## Manual fact-check process
1. Every interview note in the package is marked **simulated**.
2. Every requirement is connected to a note or marked **assumption/ethical safeguard**.
3. No names, private records, real quotes, credentials, or participant contact details were put into GitHub.
4. Owners/roles are **proposals** until the team agrees.
5. No consent, external interview, UI test, GitHub Project board, or deployed application was represented as completed.
